
 Password Strength Checker

Небольшой пет-проект на Python для оценки надёжности паролей.

Возможности

- Оценка по шкале 0–100 с уровнем: очень слабый / слабый / средний / сильный / очень сильный
- Расчёт энтропии в битах
- Проверка по списку популярных/скомпрометированных паролей
- Детекция типовых слабых паттернов:
  - последовательности символов (`abcd`, `1234`, `qwerty`)
  - повторяющиеся символы (`aaaa`)
  - похожие на дату фрагменты (`1999`, `2020`)
- Консольный интерфейс со скрытым вводом пароля (`getpass`)

 Запуск

```bash
python checker.py
```

## Использование как модуля

```python
from checker import analyze_password

result = analyze_password("MyP@ssw0rd123")
print(result)
 {'score': 72, 'level': 'Сильный', 'entropy_bits': 65.2, 'issues': [...]}
```
